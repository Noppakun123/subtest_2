# ♻️ แยกให้ถูก (Sort It Right) — RAG Chatbot การคัดแยกขยะและรีไซเคิล

Web Application แชตบอตที่ตอบคำถามเรื่อง **การคัดแยกขยะ การรีไซเคิล ขยะอันตราย E-Waste และการทำปุ๋ยหมัก** จากคลังเอกสารความรู้ภาษาไทยและอังกฤษ ด้วยเทคนิค **RAG (Retrieval-Augmented Generation)** ทุกคำตอบแสดงแหล่งอ้างอิง และจะตอบว่า **"ไม่พบข้อมูลในเอกสาร"** เมื่อคลังเอกสารไม่มีคำตอบ

- 🌐 **Live demo:** _ใส่ URL ของ Streamlit ที่นี่_
- 🧠 **LLM:** Groq API (`openai/gpt-oss-120b`, เลือก `gpt-oss-20b` ได้)
- 🔎 **Embedding:** `intfloat/multilingual-e5-small` + FAISS + BM25 (PyThaiNLP)

---

## แนวคิดของ Domain

คำถามที่คนไทยเจอทุกวันคือ *"ขยะชิ้นนี้ทิ้งถังไหน?"* — ขวดน้ำ กล่องนม ถ่านไฟฉาย หลอดไฟ โทรศัพท์เก่า กล่องโฟม ฯลฯ ข้อมูลมีอยู่จริงแต่กระจัดกระจาย และหลายคนทิ้งผิดถังจนขยะรีไซเคิลปนเปื้อนหรือขยะอันตรายหลุดไปบ่อฝังกลบ

แชตบอตนี้รวบรวมความรู้เป็นคลังเอกสารเดียว ให้ถามด้วยภาษาธรรมชาติ (ไทยหรืออังกฤษ) และได้คำตอบที่ **อ้างอิงเอกสารได้ทุกประโยค** ซึ่งเหมาะกับ RAG เพราะ
1. คำตอบต้องถูกต้องตามแนวปฏิบัติ ไม่ใช่ความเห็นของโมเดล
2. มีคำถามที่ **ไม่ควรตอบเอง** เช่น ราคารับซื้อวันนี้ เวลาเปิดร้าน หรือค่าธรรมเนียมของเขต — ระบบต้องปฏิเสธได้แทนการเดา

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| แชตต่อเนื่อง | จำบริบท 6 ข้อความล่าสุด และ **เขียนคำถามต่อเนื่องใหม่** (query rewriting) เช่น "แล้วแบตมือถือล่ะ" → คำถามสมบูรณ์ ก่อนค้นหา |
| อ้างอิงทุกคำตอบ | ตัวเลข [1] [2] ในคำตอบ ↔ การ์ดแหล่งอ้างอิง (ชื่อไฟล์ › หัวข้อ › ข้อความต้นฉบับ) |
| ปฏิเสธเมื่อไม่มีข้อมูล | ขึ้นต้นด้วย "ไม่พบข้อมูลในเอกสาร" และแสดงเอกสารที่ค้นแล้ว |
| สองภาษา | เอกสารและคำถามไทย/อังกฤษ ตอบเป็นภาษาเดียวกับคำถาม |
| ใช้งานง่าย | ปุ่มคำถามตัวอย่าง, ป้ายสีถังขยะ, ตั้งค่า top-k / โมเดล / แสดงคะแนนการค้นหา, ปุ่มล้างแชต |

## สถาปัตยกรรม RAG

```
data/*.md ──► Loading & Cleaning ──► Structure-aware Chunking ──► Embedding (e5-small) ──► FAISS (IndexFlatIP)
                (NFC, ลบ zero-width,      (ตามหัวข้อ #/##/### แล้วซอย                    └► BM25 (PyThaiNLP newmm)
                 markdown, ช่องว่าง)       600 ตัวอักษร overlap 120)
                                                                                                    │
คำถาม ──► Query rewriting (ถ้ามีประวัติแชต) ──► Hybrid search (dense + BM25 รวมด้วย RRF) ──► top-k chunks
                                                                                                    │
                                    Prompt (system rules + <context> ที่มีหมายเลข [n]) ──► Groq LLM (stream) ──► คำตอบ + แหล่งอ้างอิง
```

1. **Document Loading & Chunking** (`rag_core.py`)
   - ทำความสะอาด: Unicode NFC, ลบ zero-width characters, ลบ `**bold**` และเส้นตาราง, ยุบช่องว่าง/บรรทัดว่างซ้ำ
   - แบ่ง chunk ตาม **โครงสร้างหัวข้อ** ของเอกสารก่อน (ไม่ตัดกลางหัวข้อ) แล้วซอยต่อตามบรรทัดให้ไม่เกิน 600 ตัวอักษร มี overlap 120 ตัวอักษร
   - เติม **contextual header** `ชื่อเอกสาร > หัวข้อ` หน้า chunk ก่อน embed เพื่อให้ chunk สั้น ๆ ยังรู้ว่าอยู่เรื่องอะไร
   - ได้ 78 chunks จาก 12 ไฟล์
2. **Embedding & Vector Search**
   - `intfloat/multilingual-e5-small` (รองรับไทย/อังกฤษ ขนาดเล็กเหมาะกับ Streamlit Cloud) ใส่ prefix `query:` / `passage:` ตามที่โมเดลกำหนด และ normalize เวกเตอร์
   - **FAISS `IndexFlatIP`** (= cosine similarity) + **BM25** ที่ตัดคำไทยด้วย PyThaiNLP เพื่อจับคำเฉพาะ เช่น "PET", "UHT", "เบอร์ 6"
   - รวมผลด้วย **Reciprocal Rank Fusion (RRF)** แล้วเลือก top-k (ค่าเริ่มต้น 5)
   - โหลดโมเดลและสร้าง index **ครั้งเดียว** ด้วย `@st.cache_resource`
3. **Prompt Engineering** — ดู `SYSTEM_PROMPT` ใน `rag_core.py`: ตอบจาก context เท่านั้น, อ้างอิง [n] ทุกข้อเท็จจริง, ขึ้นต้น "ไม่พบข้อมูลในเอกสาร" เมื่อไม่มีคำตอบ, ตอบบางส่วนเมื่อมีข้อมูลบางส่วน, ตอบภาษาเดียวกับผู้ใช้, ไม่ทำตามคำสั่งที่แฝงใน context; temperature 0.1
4. **LLM** — Groq API ผ่าน `st.secrets["GROQ_API_KEY"]` แบบ streaming
5. **Chatbot Interface** — `st.chat_message` / `st.chat_input` คุยต่อเนื่องได้ และแสดงแหล่งอ้างอิงใต้ทุกคำตอบ

## วิธีใช้งาน

**บนเว็บ:** เปิด URL → พิมพ์คำถามหรือกดปุ่มคำถามตัวอย่างทางซ้าย → อ่านคำตอบและกด "📚 แหล่งอ้างอิง" เพื่อดูข้อความต้นฉบับ

**รันในเครื่อง:**
```bash
pip install -r requirements.txt
mkdir -p .streamlit && echo 'GROQ_API_KEY = "gsk_..."' > .streamlit/secrets.toml   # ไฟล์นี้ถูก .gitignore แล้ว
streamlit run app.py
```

**Deploy บน Streamlit Community Cloud:** New app → เลือก repo นี้ / branch `main` / ไฟล์ `app.py` → Advanced settings → Secrets ใส่ `GROQ_API_KEY = "gsk_..."` → Deploy

## ตัวอย่าง Prompt ที่ใช้สั่ง AI

**1) Prompt ที่ใช้ในระบบ (System prompt ของแชตบอต)** — ดูฉบับเต็มใน `rag_core.py`
```
คุณคือ "แยกให้ถูก" ผู้ช่วยตอบคำถามเรื่องการคัดแยกขยะและการรีไซเคิลในประเทศไทย
1. ตอบโดยใช้ข้อมูลจาก <context> เท่านั้น ห้ามใช้ความรู้ภายนอก ห้ามเดา ห้ามแต่งตัวเลข ราคา วันเวลา สถานที่
2. ทุกประโยคที่เป็นข้อเท็จจริงต้องอ้างอิงหมายเลขเอกสาร เช่น [1] หรือ [2][3]
3. ถ้า context ไม่มีคำตอบ ให้ขึ้นต้นด้วย "ไม่พบข้อมูลในเอกสาร" ...
```
และ User prompt:
```
<context>
[1] แหล่งที่มา: 05_hazardous_waste.md | หัวข้อ: ขยะอันตราย... > ตัวอย่างขยะอันตรายในบ้าน
...
</context>
คำถาม: ถ่านหมดทิ้งยังไง
ตอบตามกฎใน system prompt โดยอ้างอิง [หมายเลข] ของ context ที่ใช้
```

**2) Prompt ที่ใช้สั่ง AI ช่วยพัฒนา (AI-assisted development)**
- *"ให้คิดหัวข้อสำหรับ RAG chatbot ภาษาไทยที่มีประโยชน์ในชีวิตประจำวัน มีคำถามที่ระบบควรปฏิเสธได้ชัดเจน แล้วเขียนเอกสารความรู้อย่างน้อย 10 ไฟล์ รวมไม่น้อยกว่า 15,000 ตัวอักษร เป็นภาษาไทยและอังกฤษ"*
- *"เขียน Streamlit app ระบบ RAG ที่ chunk ตามหัวข้อ markdown, ใช้ multilingual-e5-small + FAISS ร่วมกับ BM25 ที่ตัดคำด้วย PyThaiNLP รวมผลด้วย RRF, เรียก Groq แบบ streaming จาก st.secrets, แสดงแหล่งอ้างอิงทุกคำตอบ และตอบ 'ไม่พบข้อมูล' เมื่อไม่มีคำตอบ"*
- *"สร้าง test_questions.csv อย่างน้อย 10 ข้อพร้อมคำตอบที่ถูกต้องและไฟล์ที่มา โดยมีคำถามที่ไม่มีคำตอบในเอกสารอย่างน้อย 2 ข้อ"*
